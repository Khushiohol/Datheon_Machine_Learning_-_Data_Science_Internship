Customer Churn Prediction

Project Overview:-
This project uses Machine Learning to predict whether customers are likely to leave a company or service.

Objective:-
To identify customers who many stop using a service based on their historical information.

Technologies Used:-

1. Python
2. Pandas
3. Numpy
4. Matplotlib.pyplot
5. Seaborn
6. Scikit-learn

Machine Learning Algorithms:-

1. Logistic Regression
2. Random Forest
